# Player state chart

Visual companion to the transition table in [MOVEMENT.md](MOVEMENT.md#state-machine).
Generated by reading every `change_to(...)` call in `src/player/states/*.gd`, so
it reflects the actual code, not just intent.

**How to view this rendered:** GitHub renders Mermaid natively. In VS Code
1.121+, it's built in too — open Preview (`Cmd+Shift+V`); if diagrams show
blank, make sure the old third-party `bierner.markdown-mermaid` extension
is uninstalled *and VS Code fully restarted* (not just reloaded), since the
two renderers conflict.

Each state's own neighborhood is broken out below so you can look at one
piece at a time. Grey dashed boxes in a diagram are states that belong to
a different section — they're shown only as the connection point; follow
the link to see their own detail.

## Big picture

Zoomed all the way out: families of states, not individual transitions.
This is the map; the sections below are the territory.

```mermaid

    Airborne["Airborne core<br/>Air"]
    Techs["Grounded techs<br/>Slide, Turnaround, LongJump"]
    Variants["Jump variants<br/>Backflip, SideFlip, TurnJump, SlideHop"]
    Pound["Ground pound chain<br/>GroundPound, PoundLand"]

    Pound --> Grounded
    Airborne --> Wall
    Wall --> Airborne
    Wall --> Grounded
    Airborne --> Ledge
    Ledge --> Grounded
    Ledge --> Airborne
    Grounded <--> DashN
    Airborne <--> DashN
    Techs --> DashN

    classDef core fill:#4c6ef5,color:#fff,stroke:#364fc7;
    classDef variant fill:#845ef7,color:#fff,stroke:#5f3dc4;
    classDef pound fill:#e8590c,color:#fff,stroke:#a94a00;
    classDef wall fill:#0ca678,color:#fff,stroke:#087f5b;

    class Wall wall
    class Techs ground
    class Ledge travel
    class DashN dash
```

- **`Air` is the universal hub** — every jump, fall, kick, or boost passes
  through it or one of its four jump variants.
- **`Dash` is reachable from almost anywhere** and always exits straight
  back to `Air` or `Run` — it never lingers.
- Nothing is a dead end: every family loops back to the grounded core
  eventually.

## Core loop — Idle, Run, Air, Dash

The state machine's resting loop. Everything else is a detour that
eventually returns here.

```mermaid
flowchart TD
    Idle:::core
    Run:::core
    Air:::core
    Dash:::dash
    GroundedTechs["Grounded techs<br/>(see below)"]:::external
    JumpVariants["Jump variants<br/>(see below)"]:::external
    GroundPound["Ground pound<br/>(see below)"]:::external
    WallTechs["Wall techs<br/>(see below)"]:::external
    LedgeGrab["Ledge Grab<br/>(see below)"]:::external

    Idle -->|falls off floor| Air
    Idle -->|jump, opposing facing @ standstill / low-speed strafe| JumpVariants
    Idle -->|plain jump| Air
    Idle -->|dash pressed| Dash
    Idle -->|gains input / speed| Run

    Run -->|falls off floor| Air
    Run -->|crouch+jump @ speed, hard reversal, crouch held| GroundedTechs
    Run -->|jump, opposing facing @ standstill / low-speed strafe| JumpVariants
    Run -->|bhop / triple jump| Air
    Run -->|dash pressed| Dash
    Run -->|no input, low speed| Idle

    Air -->|ground pound pressed| GroundPound
    Air -->|dash pressed, air dash available| Dash
    Air -->|lands, moving| Run
    Air -->|lands, still| Idle
    Air -->|ledge detected ahead| LedgeGrab
    Air -->|wall contact| WallTechs

    Dash -->|ends airborne| Air
    Dash -->|ends grounded| Run

    classDef core fill:#4c6ef5,color:#fff,stroke:#364fc7;
    classDef dash fill:#e64980,color:#fff,stroke:#a61e4d;
    classDef external fill:#e9ecef,color:#495057,stroke:#adb5bd,stroke-dasharray: 4 3;
```

## Slide

Crouch-held ground tech launched from `Run`.

```mermaid
flowchart LR
    Run:::core
    Slide:::ground
    Air:::core
    Idle:::core
    Dash:::dash
    LongJump:::ground
    SlideHop["SlideHop<br/>(jump variant)"]:::variant

    Run -->|crouch held| Slide
    Slide -->|falls / bonks| Air
    Slide -->|dash pressed| Dash
    Slide -->|release, clear geometry, moving| Run
    Slide -->|release, clear geometry, still| Idle
    Slide -->|jump + speed| LongJump
    Slide -->|jump from established slide| SlideHop

    classDef core fill:#4c6ef5,color:#fff,stroke:#364fc7;
    classDef ground fill:#f08c00,color:#fff,stroke:#b06400;
    classDef dash fill:#e64980,color:#fff,stroke:#a61e4d;
    classDef variant fill:#845ef7,color:#fff,stroke:#5f3dc4;
```

- Holding Crouch/Slide never fully arrests you — speed decays only to a
  sustain floor.
- Landing a jump *from* the slide with crouch still held re-enters `Slide`
  (via `SlideHop`, an `Air`-family state — see [jump
  variants](#jump-variants--backflip-side-flip-turn-jump-slide-hop)), so
  slide → hop → slide chains flow.

## Turnaround

Grounded skid triggered by reversing input hard while running above a
speed threshold.

```mermaid
flowchart LR
    Run:::core
    Turnaround:::ground
    Air:::core
    Idle:::core
    Dash:::dash
    TurnJump["TurnJump<br/>(jump variant)"]:::variant

    Run -->|hard input reversal @ speed| Turnaround
    Turnaround -->|falls off floor| Air
    Turnaround -->|jump during skid| TurnJump
    Turnaround -->|dash pressed| Dash
    Turnaround -->|skid finishes, moving| Run
    Turnaround -->|skid finishes, still| Idle

    classDef core fill:#4c6ef5,color:#fff,stroke:#364fc7;
    classDef ground fill:#f08c00,color:#fff,stroke:#b06400;
    classDef dash fill:#e64980,color:#fff,stroke:#a61e4d;
    classDef variant fill:#845ef7,color:#fff,stroke:#5f3dc4;
```

- Grounded-trigger only — gated off the bunny-hop landing window, so it
  never competes with a bhop.
- Letting the skid finish pivots cleanly into the new facing; jumping
  during the skid is the **Turn Jump** instead (higher apex, small forward
  pop).

## Long Jump

Crouch + jump above a speed threshold, launched from `Run` or `Slide`.

```mermaid
flowchart LR
    Run:::core
    Slide:::ground
    LongJump:::ground
    GroundPound["GroundPound<br/>(see below)"]:::external
    Air:::core

    Run -->|crouch+jump @ speed| LongJump
    Slide -->|jump + speed| LongJump
    LongJump -->|ground pound cancel| GroundPound
    LongJump -->|bonks a wall| Air
    LongJump -->|lands| Slide

    classDef core fill:#4c6ef5,color:#fff,stroke:#364fc7;
    classDef ground fill:#f08c00,color:#fff,stroke:#b06400;
    classDef external fill:#e9ecef,color:#495057,stroke:#adb5bd,stroke-dasharray: 4 3;
```

- Velocity is committed at launch — **no air control**. Ground pound is
  the only mid-air cancel; bonking a wall returns control.
- Lands into a `Slide`; enough surviving speed and an immediate re-jump
  chains into another Long Jump, Mario-64 style.

## Ground pound chain

Two-stage tech: commit to the slam in `GroundPound`, then convert on
impact in `PoundLand`.

```mermaid
flowchart LR
    Air:::core
    GroundPound:::pound
    PoundLand:::pound
    Dash:::dash
    Idle:::core

    Air -->|ground pound pressed| GroundPound
    GroundPound -->|dash pressed mid-fall: early cancel| Dash
    GroundPound -->|impact| PoundLand
    PoundLand -->|conversion window expires| Idle
    PoundLand -->|jump or dash-convert| Air

    classDef core fill:#4c6ef5,color:#fff,stroke:#364fc7;
    classDef pound fill:#e8590c,color:#fff,stroke:#a94a00;
    classDef dash fill:#e64980,color:#fff,stroke:#a61e4d;
```

- `PoundLand` opens a 0.3s conversion window: dash converts stored impact
  speed into a big horizontal boost, jump becomes a super jump, doing
  nothing just ends the pound with the momentum spent.
- Dashing mid-fall (before impact) is an early cancel into a plain air
  dash instead.

## Wall techs — Wall Run, Wall Slide

Share the same wall-contact detection; which one you get depends purely on
incoming tangential speed.

```mermaid
flowchart LR
    Air:::core
    WallRun:::wall
    WallSlide:::wall
    Run:::core

    Air -->|wall contact, fast tangential speed| WallRun
    Air -->|wall contact, slow / falling| WallSlide
    WallRun -->|expires / kicks off| Air
    WallRun -->|touches down| Run
    WallRun -->|run decays, still holding wall| WallSlide
    WallSlide -->|kicks off / releases| Air
    WallSlide -->|touches down| Run

    classDef core fill:#4c6ef5,color:#fff,stroke:#364fc7;
    classDef wall fill:#0ca678,color:#fff,stroke:#087f5b;
```

- `WallSlide` is the low-speed chimney tool (two facing walls = climbable
  chimney); `WallRun` is the high-speed traversal tool.
- A `WallRun` that runs out of time decays into a `WallSlide` if you're
  still holding toward the wall.

## Jump variants — Backflip, Side Flip, Turn Jump, Slide Hop

These four don't transition *between* each other — each just has its own
entry trigger, then **inherits `AirState`'s entire `physics_update()`
wholesale** (`extends AirState` in code). So once launched, all four fly,
land, wall-contact, and ledge-grab exactly like plain `Air`, including
every exit `Air` has (`GroundPound`, `Dash`, `Run`, `Idle`, `LedgeGrab`,
`WallRun`, `WallSlide`). The one variant-specific rule: buffering a jump on
the landing frame (a bunny hop) snaps you into plain `Air` rather than
replaying the variant's launch animation.

```mermaid
flowchart LR
    Idle:::core
    Run:::core
    Turnaround:::ground
    Slide:::ground
    Backflip:::variant
    SideFlip:::variant
    TurnJump:::variant
    SlideHop:::variant
    Air:::core

    Idle -->|jump, opposing facing @ standstill| Backflip
    Run -->|jump, opposing facing @ standstill| Backflip
    Idle -->|jump, low-speed strafe| SideFlip
    Run -->|jump, low-speed strafe| SideFlip
    Turnaround -->|jump during skid| TurnJump
    Slide -->|jump from established slide| SlideHop

    Backflip -.->|flies exactly like Air| Air
    SideFlip -.->|flies exactly like Air| Air
    TurnJump -.->|flies exactly like Air| Air
    SlideHop -.->|flies exactly like Air| Air

    classDef core fill:#4c6ef5,color:#fff,stroke:#364fc7;
    classDef ground fill:#f08c00,color:#fff,stroke:#b06400;
    classDef variant fill:#845ef7,color:#fff,stroke:#5f3dc4;
```

- **Backflip** — near-standstill, pushing away from facing.
- **Side Flip** — low-speed strafing input.
- **Turn Jump** — jump during a `Turnaround` skid.
- **Slide Hop** — jump out of an established `Slide`.

All four give a small pop in a variant-specific direction with *no forward
commitment* (the opposite of Long Jump) and otherwise fly like a normal
jump.

## Traversal — Ledge Grab

Auto-mantle, only entered from `Air`.

```mermaid
flowchart LR
    Air:::core
    LedgeGrab:::travel
    Run:::core
    Idle:::core

    Air -->|ledge lip detected ahead| LedgeGrab
    LedgeGrab -->|jump / drop mid-hang| Air
    LedgeGrab -->|mantle done, moving| Run
    LedgeGrab -->|mantle done, still| Idle

    classDef core fill:#4c6ef5,color:#fff,stroke:#364fc7;
    classDef travel fill:#1098ad,color:#fff,stroke:#0b7285;
```

- Triggered near apex or while falling toward a ledge lip (raycast probe).
- Brief hang, then automatic mantle onto the lip. During the hang: jump
  wall-kicks away, crouch drops.
